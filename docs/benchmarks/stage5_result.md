# Stage 5 result: gate PASSED on the first official run (2026-10-20)

Raw data: `results/stage5/` (commit `4d3d917`, clean tree). The criteria
are in `docs/benchmarks/stage5_adjoint.md` and were not changed.
Development runs preceded the official run, as in every stage. They found
two runner bugs (a cold-started BV sweep, and an undefined relative error
when a single-node FD is exactly zero) and no adjoint or criterion issue.

| Criterion | Result | Worst over 5 directions (threshold) |
|---|---|---|
| S5a A1, $\int\psi$ (stage 2) | pass | 3.6e-9 (1e-6) |
| S5b A2, diode current (stage 3) | pass | 4.7e-7 (1e-3) |
| S5c A3, breakdown index B (stage 4) | pass | 4.0e-9 (1e-6); argmax element unchanged in every FD solve |
| S5d A4, field-based BV (stage 4, ZA19 eq. 14) | pass | 6.8e-7 (1e-4); argmax unchanged |
| S5e cost of one adjoint gradient / one Newton iteration | pass | 0.98 (≤ 3) |

**Reported:**
- A2s (with SRH): 1.5e-6.
- $\partial B/\partial V_R$: adjoint 4.2522521e-3, FD 4.2522521e-3 (agree to 6e-9 relative).
- An FD gradient over all 1023 design variables would take about 30.7 s, about **1.1×10⁴** times the adjoint's 2.8 ms.
- Single-node checks: ≤ 2.9e-6 relative except A4. There, all absolute errors are about 1e-9, which is the Brent BV noise floor ($10^{-12}/\epsilon$). One node in the neutral region has a true sensitivity of only 3e-8, so its relative error is 2.7%. That is FD noise, not adjoint error.
- In A3, three single nodes far from the junction have FD exactly 0 and adjoint ≤ 8e-12.

**Physical plausibility** (`figures/stage5_sensitivity_maps.png`, generated by
`benchmarks/stage5/plot.py`): with the ZA19 sign convention ($D=N_A-N_D$),
the current sensitivity is uniform and of opposite sign in the two neutral
regions, consistent with $j\propto1/(N W)$. The field-based-BV sensitivity
is positive in the n drift region and falls linearly to zero at the
depletion edge. Lowering the drift doping near the junction therefore raises
the field-based BV, which is qualitatively the same conclusion as ZA19.

**Verified:** discrete adjoint gradients of these four objectives, with
respect to interior nodal net doping, on the verified 1D forward models of
stages 2–4.

**Not claimed:** the paper's device results; any optimisation (stage 6); 2D;
SiC parameters; smooth surrogates for the max in $B$ (B is differentiable
only while its argmax element is unchanged, as checked here).
