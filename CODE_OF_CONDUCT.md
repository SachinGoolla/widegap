# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, by reference.
The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Expected behaviour

In short, everyone taking part in this project is expected to:

- Treat contributors, reviewers and users with respect, whatever their background or experience.
- Give and accept technical criticism on the science and code, not on the person.
- Be honest about results, including negative results, uncertainty and limitations.
- Credit prior work and independent implementations fairly, and report disagreements openly.
- Keep discussion focused on the project, and avoid harassment or personal attacks.

## Reporting and enforcement

Instances of unacceptable behaviour can be reported by opening a confidential report by contacting the maintainer via the GitHub profile https://github.com/SachinGoolla.

The maintainer will review each report and decide on a response that is proportionate to the situation, following the enforcement guidelines in the Contributor Covenant 2.1.
